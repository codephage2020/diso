# diso — 深入浅出

Explain `$ARGUMENTS` to an intelligent adult new to the subject, in the request language, as ONE self-contained HTML file written directly to the user's workspace as `diso-<topic>.html`. Open in any browser; no server.

Read [base.html](base.html) first — it is the shell you copy: keep its `<!DOCTYPE>`, `<head>`, and the entire `<style>` block **verbatim**, then replace the body content. Consistency comes from copying the real stylesheet, not from memory.

## Page contract

`hero` (title + one-sentence essence) → Part 1 · Build the intuition (4–6 `.step` blocks, each: `.step-num` + `.step-label`, hand-drawn inline `<svg>`, `.step-txt`) → Part 2 · The real mechanism (mapping table: analogy role / real component / note, then the mechanism prose) → Part 3 · Why designed this way (trade-offs; `.versus` for one gained-vs-cost pair, `.stats` for order-of-magnitude facts) → sources (real, linked) → `takeaway` (one-sentence summary, dark block) → colophon (`YYYY-MM-DD · Generated by diso`). Right-edge `.toc` links every section id.

Modes: default = full page. `--kid` = drop Part 3, compact mechanism. `--deep` = add a `<details>` formal section (assumptions, boundary conditions) between Parts 2 and 3.

## The only rules that matter

- Zero JavaScript, zero external assets, zero web fonts. Everything inline.
- Every `<svg>` carries `<title>` and `<desc>`; viewBox width 960; parchment `#f5f4ed` background.
- Two accent hues, divided semantically: celadon `#78C2C4` (wash) / `#267072` (ink) for focus and gains; terracotta `#C47A78` / `#8C4644` for cost and failure. Never swap, never a third hue. Washes are fills only — text and thin lines use inks.
- Diagrams: orthogonal edges only (no diagonals, no curves), arrowheads are hand-drawn chevron paths (never `<marker>`), coordinates land on a 4px grid, solid accent fills ≤ 5% of canvas.
- Weights 400/500 only. No shadows, no italics, no pure white. Localize every visible string to the request language.

Cite sources for factual claims; label teaching assumptions. Return the HTML link when done.
